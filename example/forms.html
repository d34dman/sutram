A form that changes as you fill it

A support request. Pick a topic and the form asks for more: an invoice for billing, a product and steps for a bug. Ask for a call back and it wants a phone number. A schema written up front cannot describe fields that do not exist yet; commands can, because the agent asks again.

Press ` and try:

  • form fields request, then form set request topic billing and form fields request again
  • form set request invoice 2024-17: the error says what an invoice number looks like
  • form submit request before everything is filled in: it names the missing fields
  • form status request, form discard request: discard puts back what the form started with
