Sutram example

Press the key left of 1 (` on US keyboards, ^ on German ones), or Ctrl with it inside a text field, to open the console. Try:

  • help, status, man todo add
  • todo add "Buy beans", todo list, todo list --json
  • todo done 1, todo clear (asks first)
  • Tab completes commands, options and values: todo done Tab lists the open todos
  • todo add "Buy beans, Enter inside the quotes starts a new line of the title
  • Paste todo add a, todo add b, todo done 99 as three lines: the batch fails and undoes the first two

Show the console inline, the way an app places it in its own panel.
