Make your web app ready for AI agents.

The problem

Today, agents guess their way through your app

An agent that can't see your app's actions has to read the page, guess what to click, and read it again to find out whether it worked. Sutram gives it the actions directly, and answers it can act on.

Without Sutram

  1. Read the whole page, or take a screenshot
  2. Guess which element is the field or the button
  3. Click, type, then read the page again
  4. No error message: work out what went wrong
  5. Start over when the layout changes

With Sutram

› form set request topic billing
topic set. The form now also asks for: invoice, amount.
› form set request invoice 2024-17
form set: "2024-17" is not a valid invoice number.
Use INV- and at least four digits, such as INV-20417.
› form set request invoice INV-20417
invoice set.

How it works

Write a few lines per action. Every agent can use it.

Give each action a name, a JSON Schema for its input, and a function. Sutram does the rest: the tools, the console, the help pages and the input checks.

You writeapp.js
Sutram.register({ name: "cart add", provider: "cart", description: "Add a product to the cart", input: { // JSON Schema type: "object", properties: { sku: { type: "string" }, qty: { type: "integer", default: 1 } }, required: ["sku"], }, annotations: {}, // readOnly, consequential… run: ({ sku, qty }) => cart.add(sku, qty), });
Agents and people getsame checks, same function
WebMCPcart_add({ "sku": "V60-02", "qty": 2 })
ScriptSutram.call("cart_add", { sku: "V60-02", qty: 2 })
Console› cart add --sku=V60-02 --qty=2

Also generated from the same definition

  • Input checks, with errors that name the field and the fix
  • Help, manual pages and Tab completion in the console
  • A question to the person before consequential actions
  • One status of the whole page for agents

        FAQ
        
    Questions you might have
    
        
    Something missing? Ask on GitHub.
    
      
    
      
    
        
    
          Why not build an API or an MCP server instead?
          
    For server-to-server work, do. Sutram is for the app the user already has open: commands run in the browser, in the user's logged-in session, and call your own code and endpoints. There is no new backend, no new login and no token to hand out.
    
        
    
        
    
          Is it safe to let agents act in my app?
          
    An agent can do exactly what the user could already do, and nothing more: access checks stay on your server. Mark an action consequential, and the person is asked before an agent runs it.
    
        
    
        
    
          How is this different from Playwright or browser-use?
          
    Those drive a browser. Sutram gives them something better to drive: instead of reading the page and clicking, they call Sutram.call("cart_add", …), get data back, and get errors that say what to fix.
    
        
    
        
    
          Do browsers support WebMCP yet?
          
    Support is still arriving, which is why Sutram doesn't depend on it. Browser agents and tests use your commands today, and browsers with WebMCP get them as native tools. Nothing changes in your code when support arrives.
    
        
    
        
    
          What does it cost to add?
          
    One script with no dependencies, about 31 kB gzipped when minified, and about ten lines for each action. It works with any framework, or none.
    
        
    
        
    
          Is it ready for production?
          
    Sutram is at version 0.4: open source, tested, and published on npm and drupal.org. The command contract may still change before 1.0, and until then breaking changes bump the minor version. See the changelog.
    
        
    
        
    
          I build on Drupal. Is there a module?
          
    Yes: composer require drupal/sutram. It ships the package build, and its demo modules expose menus, pages and node forms as commands. See the Drupal demo.

          Read the quick start 
          Star on GitHub
        
    
        
    Or npm i @d34dman/sutram · on Drupal, composer require drupal/sutram
    
      
    
      
    <script type="module">
  import Sutram from
    "https://cdn.jsdelivr.net/npm/@d34dman/sutram@0.4/dist/sutram.js";

  Sutram.register({
    name: "hello world",
    provider: "hello",
    description: "Say hello",
    input: {
      type: "object",
      properties: { who: { type: "string", default: "you" } },
    },
    positional: ["who"],
    annotations: { readOnly: true },
    run: ({ who }) => ({ text: `Hello, ${who}.` }),
  });
  Sutram.mountConsole();
</script>
